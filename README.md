# ATCS Project Website Repository

This repository hosts **only the static website** for the Active Tremor Compensation Spoon (ATCS) project. It does **not** contain the underlying source code or hardware design files of the ATCS system.

## Repository Structure
- `index.html` – Main entry point for the website
- `assets/` – Contains all images, PDFs, and other media assets used by the site.
- `README.md` – This documentation file.
